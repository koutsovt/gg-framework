The detector contract — five clauses
01
Pure function
Bars in, events out. No state, no I/O, no randomness — same input gives identical output, which is what makes the honesty harness reproducible.
02
No lookahead
At bar t the detector reads bar t and earlier — never t+1. Enforced structurally: it is handed a left-bounded window only.
03
Events, not booleans
Output is typed objects with a time index and price geometry. No "strength" score — that is a discretion word wearing a number.
04
Maturity timestamp
Each event carries the bar at which it became confirmed. An FVG spans three bars but is only knowable once bar 3 closes — the zone appears on the scope exactly then.
05
Self-parameterised
Every threshold arrives as an explicit argument bound by the setup. The detector ships no defaults — if min_size_atr is not passed, it does not run. That is what lets the Definition Layer reject an unbound parameter before any data is touched.
Lookahead probe — the guardrail behind clause 02

The single most common way a backtest manufactures a fake edge is a detector quietly reading the future. The probe runs the detector on the candle window, then re-runs it on the same window with future candles appended, and asserts the labels over the shared region are byte-identical. If they differ, every backtest using this detector is fiction.
